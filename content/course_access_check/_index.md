# Course Access Check

Please verify that your connection can access all the resources necessary to follow GDQuest courses.

### Essential:

- [GDQuest (www.gdquest.com)](https://www.gdquest.com/favicon.ico): the "Learn GDScript" application is stored there.
- [GDSchool (school.gdquest.com)](https://school.gdquest.com/opengraph-image.png): the main site to access lessons, quizzes, and track your progress. 
- [GDSchool projects repository](https://aipqadxyfpdcvlwpnxbu.supabase.co/storage/v1/object/public/test/gdquest-logo.svg): necessary for the project files.

### Non-Essential:

- [Videos](https://player.vimeo.com/favicon.ico): those serve to occasionally illustrate a point in the lessons.
